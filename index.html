This page holds no data of its own. It reads and writes your private GitHub repository using an access token that is stored only in this browser. Enter it once per device.

The token needs access to that one repository only, with Contents and Actions set to read and write. The trading token is a second one, for the dip-trader repository only, with Actions set to read and write and Contents set to read-only. It can start an order but cannot change the safety limits. Anyone with this browser profile can use these, so don't save them on a shared computer.
